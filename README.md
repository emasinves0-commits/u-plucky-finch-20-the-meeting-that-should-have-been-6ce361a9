A one-line joke program for the make.fun bounty "The Meeting That Should Have Been an Email". It validates a single line of text and writes it to `/output/entry.txt`. The joke is a zombie calendar invite: the meeting outlived everything that once justified it.

> The meeting that should have been an email outlived the project, the team, and the people — it still meets every Tuesday, alone, on time.

Run it with `node main.ts`.
